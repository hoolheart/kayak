## 依赖组件与 API

### 后端 API

| API | 方法 | 说明 |
|-----|------|------|
| `GET /api/v1/methods` | GET | 方法列表（分页，query: `page`, `size`） |
| `GET /api/v1/methods/{id}` | GET | 方法详情 |
| `POST /api/v1/methods` | POST | 创建方法 (body: `name`, `description`, `process_definition`, `parameter_schema`) |
| `PUT /api/v1/methods/{id}` | PUT | 更新方法 (body: `name?`, `description?`, `process_definition?`, `parameter_schema?`) |
| `DELETE /api/v1/methods/{id}` | DELETE | 删除方法 |
| `POST /api/v1/methods/validate` | POST | 验证方法定义 (body: `process_definition`) |

### 后端验证错误码

| 错误类型 | HTTP 状态码 | 前端期望显示 |
|----------|:----------:|------------|
| 方法不存在 | 404 | "方法不存在" |
| 无权操作 | 403 | "无权操作此方法" |
| 验证失败 | 400 | 服务端返回的具体验证错误消息 |
| 数据库错误 | 500 | "数据库操作失败"（通用错误） |

### 前端组件

| 组件 | 文件 | 说明 |
|------|------|------|
| MethodListPage | `lib/pages/method/method_list_page.dart` | 方法列表页 |

| MethodListNotifier | `lib/providers/method_provider.dart` | 列表 Provider |
| MethodDetailNotifier | `lib/providers/method_provider.dart` | 详情/编辑 Provider |
| MethodService | `lib/services/method_service.dart` | 方法 API 封装（TASK-022 已创建 list/getById） |
| AsyncValueWidget | `lib/widgets/async_value_widget.dart` | 三态 Widget（TASK-007） |
| ErrorView | `lib/widgets/error_view.dart` | 错误状态组件（TASK-007） |
| EmptyView | `lib/widgets/empty_view.dart` | 空状态组件（TASK-007） |
| SkeletonCard | `lib/widgets/skeleton.dart` | 骨架屏组件（TASK-007） |

### 数据模型

| 模型 | 关键字段 |
|------|----------|
| `Method` | id, name, description?, processDefinition, parameterSchema, version, createdBy, createdAt, updatedAt, parameters? |
| `MethodParameter` | key, type, label?, defaultValue?, isRequired, unit?, description?, min?, max?, options? |
| `MethodListResponse` | items: List\<Method\>, total: int, page: int, size: int |
| `ValidationResult` | valid: bool, errors: List\<String\> |

### 路由

|------|------|------|
