**测试步骤**：
1. 输入 `"abc"`（弱：仅小写字母 < 6 字符）→ score ≈ 0

**预期结果**：

| 密码 | 段数 | 颜色 | 等级标签 |

| `"abc"` | 1 | error（红） | 弱 |
| `"abcdefgh"` | 1-2 | error（红） | 弱 |
| `"Abcdef1"` | 3 | primary（蓝） | 好 |
| `"Abcdef1!"` | 4 | primary（蓝） | 强 |
| `"Abcdefghijk1!"` | 4 | primary（蓝） | 强 |

**失败判定**：
- ❌ 等级标签与实际强度不匹配
- ❌ 段数和颜色与 `_getStrengthLevel` 逻辑不符
