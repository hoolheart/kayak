## 3. 发现的 Bug

### BUG-023-001: ConfirmDialog 在标准屏幕宽度下 Row 溢出 — ✅ 已修复 (2026-06-08)

- **状态**: ✅ 已修复
- **严重级别**: Medium
- **触发条件**: 在任意试验状态下点击"停止"按钮，弹出确认对话框
- **现象**: `ConfirmDialog` 的按钮行（`Row` at `confirm_dialog.dart:209`）在 `296px` 约束下溢出 `38px`
- **根因**: AlertDialog 默认最大宽度为 560px，内容区域约 296px。"Cancel"按钮 + 间距 + "Confirm Stop"按钮的总宽度超过可用空间
- **修复**: sw-tom 已修复，3 个相关测试 (TC-CP-STOP-001, TC-CP-STOP-002, TC-CP-STOP-004) 全部通过
- **影响测试**: ~~TC-CP-STOP-001, TC-CP-STOP-002, TC-CP-STOP-004~~ (已全部通过)

### BUG-023-002: 控制面板在不同屏幕宽度下 RenderFlex 溢出 — ⚠️ 部分修复 (2026-06-08)

- **状态**: ⚠️ 部分修复 (3/4 子问题已修复)
- **严重级别**: Medium
- **触发条件**: 屏幕宽度 ≤ 900px 且试验状态为 IDLE/LOADED/RUNNING
- **原始现象**: 控制面板内容（信息卡片 + 按钮组 + 状态显示）总和超过可用高度，导致底部溢出
- **根因**: 移动端布局中控制面板被限制在 `maxHeight: 50vh`，但内部 `Column` 没有设置 `shrinkWrap` 或使用 `SingleChildScrollView`
- **修复状态**:
  - ✅ TC-RESP-003 (599px): 垂直溢出已修复 — 窄屏使用 Wrap 布局
  - ✅ TC-RESP-004 (399px): 垂直溢出已修复 — 窄屏自适应
  - ❌ TC-RESP-002 (900px): **仍失败** — 控制面板 Row 按钮行水平溢出 59px (`experiment_console_page.dart:1440`)
- **影响测试**: TC-RESP-002 (仍失败), ~~TC-RESP-003~~ (已通过), ~~TC-RESP-004~~ (已通过)

### 4.2 覆盖缺口说明

以下测试用例未通过 Widget 测试覆盖，原因及建议：

1. **日志滚动测试 (6 个)**: 需要真实的 `ScrollController` 交互，在 Widget 测试中难以精确模拟用户滚动行为。建议使用集成测试。
2. **WS 重连全流程 (5 个)**: 需要真实的 Timer/Duration 延迟，Widget 测试中 fakeAsync 可能与 Timer.periodic 冲突。建议在 Provider 层单元测试中覆盖。
3. **WS 竞争状态 (TC-EDGE-007, TC-EDGE-008)**: 需要精确控制异步时序，建议在 Provider 测试中模拟。
4. **状态变更历史时间线 (TC-COMP-004, 005)**: 该功能尚未在代码中实现（仅显示完成信息，未显示历史时间线）。
5. **日志实时追加 (TC-LOG-DISPLAY-010)**: 需要后端轮询机制支持，当前 Widget 测试中轮询未激活。
6. **浏览器前进后退 (TC-NAV-005)**: `GoRouter` 在 Widget 测试环境中不支持 `pop` 操作。
7. **日志字体检查 (TC-LOG-DISPLAY-001)**: 字体渲染需要 `fontFamily` 样式断言，不在本文测试范围。
8. **按钮 HTTP 错误/网络失败 (TC-CP-FEEDBACK-005, 006)**: 需要 mock notifier 的异步操作并控制返回结果。
