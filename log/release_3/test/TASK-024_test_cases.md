### 0.2 后端数据依赖

| 数据项 | 后端 API | 响应关键字段 |
|--------|----------|-------------|
| 用户名 | `GET /api/v1/auth/me` | `username` |
| 工作台总数 | `GET /api/v1/workbenches?page=1&size=1` | `total` |
| 最近工作台 | `GET /api/v1/workbenches?page=1&size=4` | `items[0..3]`, `device_count` (per item if available) |
| 试验总数 | `GET /api/v1/experiments?page=1&size=1` | `total` |
| 设备总数 | `GET /api/v1/workbenches/*/devices` (per workbench) | 聚合计数 |

> **注意**：设备总数在后端无全局聚合端点。`DashboardService` 需按工作台逐个获取设备列表并累加计数，或使用后端 `GET /api/v1/workbenches/{id}` 返回的 `point_count`（如果 WorkbenchDto 包含该字段）。需与 sw-tom 确认设备的聚合策略。

### 0.3 状态模型

仪表盘采用**按区域独立容错**策略：每个区域（欢迎区、快捷操作、统计概览、最近工作台）独立维护自己的加载/数据/错误状态，一个区域失败不影响其他区域正常渲染。

```
每个区域独立状态机:
IDLE → LOADING → LOADED (data present)
              → EMPTY  (all counts = 0, no workbenches)
              → ERROR  (API failure — 仅影响本区域)
```

| 时间段 (24h) | 问候语 (zh) | 问候语 (en) |
|:-----------:|------------|------------|
| 06:00-11:59 | 早上好 | Good morning |
| 12:00-17:59 | 下午好 | Good afternoon |
| 18:00-05:59 | 晚上好 | Good evening |
