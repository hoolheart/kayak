## 4. 交互原型 (Prototyping)

### 4.1 用户流程 1: 选择数据并加载

```
[Desktop-1440-Initial]
  → 点击试验 Dropdown
    → [State-Dropdown-Open] (下拉框展开, 显示试验列表)
      → 选择"温度循环测试"
        → [Desktop-1440-Initial] (设备 Dropdown 变为可用)
          → 点击设备 Dropdown
            → 选择"温度传感器-01"
              → [Desktop-1440-Initial] (测点复选框出现)
                → 勾选"温度"
                  → 勾选"压力"
                    → 勾选"湿度"
                      → [State-Point-Selected-4] (4个已选)
                        → 点击"加载数据"
                          → [Desktop-1440-Loading] (300ms)
                            → [Desktop-1440-With-Data] (图表淡入)
```

### 4.2 用户流程 2: 查看数据表格

```
[Desktop-1440-With-Data]
  → 开启"数据表格" Switch
    → [Desktop-1440-With-Table] (表格从底部展开, 200ms 动画)
      → 滚动表格
        → 表格内容滚动, 表头 sticky
          → 关闭"数据表格" Switch
            → [Desktop-1440-With-Data] (表格收起)
```

### 4.3 用户流程 3: 图表交互

```
[Desktop-1440-With-Data]
  → 鼠标悬停图表
    → [Desktop-1440-Tooltip] (显示 Tooltip)
      → 移动鼠标
        → Tooltip 跟随移动, 内容实时更新
          → 滚轮放大
            → [Desktop-1440-Zoomed] (X轴范围缩小)
              → 拖拽平移
                → 图表左右移动
                  → 点击图例"压力"
                    → 压力曲线隐藏, 图例项变灰
```

## 8. 设计决策记录

### 决策 1: 控制面板固定宽度而非可拖拽
- **原因**: 简化实现, 350px 足够容纳所有控件
- **替代方案**: 可拖拽调整宽度 (Grafana 风格) — 放到未来版本

### 决策 2: 测点颜色固定分配
- **原因**: 保持颜色稳定, 用户形成颜色-测点关联记忆
- **分配方式**: 按顺序固定 (#1红, #2绿, #3蓝, #4橙)

### 决策 3: 单 Y 轴而非多 Y 轴
- **原因**: fl_chart 1.2.0 多 Y 轴支持有限, 简化实现
- **注意**: 如果测点数值范围差异极大, 小数值曲线可能不可见

### 决策 4: 降采样使用对数刻度滑块
- **原因**: 100-10,000 范围大, 线性滑块低频区分辨率低
- **实现**: slider 线性映射到对数值

### 决策 5: 图表交互仅支持桌面端滚轮/拖拽
- **原因**: 移动端触摸交互 (双指缩放/单指平移) 需要额外实现
- **移动端降级**: 显示完整数据范围, 不支持缩放平移

### 决策 6: 数据表格默认隐藏
- **原因**: 最大化图表区域, 用户按需查看原始数据
- **记忆**: 用户的显示/隐藏偏好可本地存储

## 9. 与开发团队的交接说明

### fl_chart 1.2.0 关键配置

```dart
LineChartData(
  gridData: FlGridData(
    show: true,
    drawVerticalLine: true,
    horizontalInterval: 1,
    verticalInterval: 1,
    getDrawingHorizontalLine: (value) => FlLine(
      color: Colors.grey.withOpacity(0.3),
      strokeWidth: 1,
    ),
    getDrawingVerticalLine: (value) => FlLine(
      color: Colors.grey.withOpacity(0.3),
      strokeWidth: 1,
    ),
  ),
  titlesData: FlTitlesData(
    bottomTitles: AxisTitles(
      sideTitles: SideTitles(
        showTitles: true,
        getTitlesWidget: (value, meta) {
          // 时间格式化
        },
      ),
    ),
  ),
  lineTouchData: LineTouchData(
    touchTooltipData: LineTouchTooltipData(
      tooltipRoundedRadius: 8,
      getTooltipItems: (touchedSpots) {
        // 自定义 tooltip
      },
    ),
  ),
)
```

### 缩放平移实现建议

使用 `fl_chart` 的 `minX`, `maxX` 属性控制可见范围:
- 滚轮事件 → 调整 `minX` / `maxX` (以鼠标位置为中心)
- 拖拽事件 → 平移 `minX` / `maxX`
- 重置按钮 → 恢复初始范围

### 性能注意事项

- 超过 5000 数据点时隐藏数据点圆点
- 使用 `LineChartBarData.dotData.show = false` 提升性能
- 考虑使用 `LineChartBarData.preventCurveOverShooting = true`
