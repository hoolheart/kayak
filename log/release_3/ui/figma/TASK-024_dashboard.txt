## 标注与说明

### 响应式行为标注

**Desktop (> 1200px)**:
```
- NavigationRail: extended, 220px width
- Content: max-width 1200px, centered
- Quick Actions: 4 columns grid
- Stats: 3 columns, horizontal
- Recent Workbenches: 4 cards, 240px each
- Padding: 32px
```

**Tablet (600-1200px)**:
```
- NavigationRail: collapsed (72px) or extended toggle
- Content: full width, adaptive
- Quick Actions: 2 columns grid
- Stats: 3 columns (or 2 + 1 wrap)
- Recent Workbenches: 3 visible, 200px each
- Padding: 24px
```

**Mobile (< 600px)**:
```
- BottomNavigationBar: 6 items
- Content: full width
- Quick Actions: 2 columns (compact cards)
- Stats: flex wrap, 3 cards min-width 100px
- Recent Workbenches: horizontal scroll, 180px each
- Padding: 16px
```

### 无障碍标注

- **Welcome Section**: aria-label="欢迎区域，{greeting}，{username}，{date}"
- **Quick Cards**: Semantics label="{title}，{subtitle}，点击进入"
- **Stat Cards**: aria-label="{label}，数量 {number}"
- **Recent Workbench Cards**: aria-label="{name}，{device_count}，最近活动 {updated_at}"
- **最小触摸目标**: 所有卡片和按钮 ≥ 48×48dp
- **颜色对比度**: 文字 ≥ 4.5:1, 大文字 ≥ 3:1

### 性能标注

- **骨架屏**: 使用现有 Skeleton 组件，shimmer 动画 GPU 加速
- **卡片网格**: 使用 Wrap + ConstrainedBox，避免重排
- **数字动画**: 数据加载完成后，数字从 0 计数动画到目标值 (600ms, ease-out)
- **区域独立加载**: 每个区域独立请求，避免瀑布等待

### 按区域独立容错策略

```
Region: Welcome
  - Data Source: Auth Provider (cached)
  - Error Behavior: 回退为仅显示日期，无用户名
  - Loading Behavior: 文字骨架

Region: Quick Actions
  - Data Source: Static (no API)
  - Error Behavior: N/A (始终显示)
  - Loading Behavior: 卡片骨架

Region: Stats Overview
  - Data Source: GET /api/v1/workbenches, /api/v1/experiments
  - Error Behavior: ErrorView + 本区域重试按钮
  - Loading Behavior: 数字卡片骨架
  - Empty Behavior: 显示 "0"

Region: Recent Workbenches
  - Data Source: GET /api/v1/workbenches?page=1&size=4
  - Error Behavior: ErrorView + 本区域重试按钮
  - Loading Behavior: 水平卡片骨架
  - Empty Behavior: EmptyView + 创建引导按钮
```
