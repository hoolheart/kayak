### 元素规格

| 元素 | 位置 | 尺寸 | 样式 |
|------|------|------|------|

| 标题 | AppBar 左侧 | — | Title Large, 22px, On Background |
| 创建按钮 | AppBar 右侧 | 高 40px | Filled Button, Primary, "+ 创建试验" |
| 筛选栏 | AppBar 下方 | 自适应 | Surface, 内边距 16px, 底部边框 |

| 重置按钮 | 筛选栏右侧 | — | Text Button "重置筛选" |
| 表格区 | 内容区 | 宽 100% | DataTable |
| 表头 | 表格首行 | 高 48px | Surface Variant 50%, Label Medium |
| 数据行 | 表头下方 | 高 52px | 透明背景，底部 1px 分隔线 |
| 名称列 | 第 1 列 | flex: 2 | Body Medium, 单行省略 |
| 方法列 | 第 2 列 | flex: 1 | Body Medium, On Surface Variant |

| 开始时间列 | 第 4 列 | 160px | Body Medium, YYYY-MM-DD HH:mm |
| 持续时间列 | 第 5 列 | 100px | Body Medium, 右对齐, HH:mm:ss |
| 操作列 | 第 6 列 | 120px | IconButton 组, 右对齐 |
| 分页栏 | 底部 | 48px | Surface, 顶部边框, 两端对齐 |

### 交互说明

- **Hover 行**: 背景变为 On Surface 4%
- **Hover 操作按钮**: 对应按钮背景色变化（8% 状态色）
- **点击行**: 导航到试验详情页 `/experiments/{id}`
- **点击操作按钮**: 执行对应操作（可能需要确认对话框）
- **RUNNING 行**: 微弱绿色背景 tint (Success at 4%)
- **状态筛选变化**: 选择下拉选项后实时刷新表格，URL query 同步更新 (?status=RUNNING)
- **筛选变化**: 实时刷新表格，URL query 同步更新

## 交互流程图

### 筛选流程

```
用户操作
  ├── 选择状态下拉选项
  │     → 选中单项状态（或"全部状态"）
  │     → 更新 URL query (?status=RUNNING)
  │     → API 请求带筛选参数
  │     → 表格显示 loading → 刷新数据
  │     → 有数据: 显示表格
  │     → 无数据: 显示筛选空状态 (Screen 5)
  │
  ├── 选择时间范围
  │     → 验证日期有效性
  │     → 更新 URL query (?start=2026-05-01&end=2026-06-01)
  │     → 同上刷新流程
  │
  └── 点击"重置筛选"
        → 状态恢复为"全部状态"
        → 清除时间范围
        → 重置 URL query
        → 刷新列表（无筛选）
```

### 试验操作状态机

```
                    ┌─────────┐
                    │  IDLE   │
                    └────┬────┘
                         │ 加载配置
                    ┌────▼────┐
                    │ LOADED  │
                    └────┬────┘
           ┌─────────────┼─────────────┐
           │ 启动        │ 编辑        │ 删除
      ┌────▼────┐   ┌───┴───┐    ┌────▼────┐
      │ RUNNING │   │(编辑页)│    │ (删除)  │
      └────┬────┘   └───────┘    └─────────┘
           │
     ┌─────┴─────┐
     │ 暂停      │ 停止/终止
┌────▼────┐ ┌────▼────┐
│ PAUSED  │ │ ABORTED │
└────┬────┘ └────┬────┘
     │ 继续      │ 删除
┌────▼────┐ ┌────▼────┐
│ RUNNING │ │ (删除)  │
└─────────┘ └─────────┘

COMPLETED 状态:
RUNNING ──(正常结束)──→ COMPLETED ──(删除)──→ (删除)
```

### 页面状态流转

```
初始加载
  → Loading (Skeleton)
    → 成功
      → 有数据 → Data (Table/Card)
      → 无数据 → Empty (Screen 2)
    → 失败 → Error (Screen 4)

筛选操作
  Data ──(筛选无结果)──→ Empty Filtered (Screen 5)
  Empty Filtered ──(清除筛选)──→ Data

分页操作
  Data ──(切换页码)──→ Loading (Skeleton) ──→ Data (新页)

刷新操作
  Data ──(下拉刷新/点击刷新)──→ Loading (保留数据+进度条) ──→ Data (更新)
```
