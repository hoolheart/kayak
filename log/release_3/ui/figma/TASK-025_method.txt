### 元素规格

| 元素 | 位置 | 尺寸 | 样式 |
|------|------|------|------|
| AppBar | 顶部 | 64px | Surface，底部 1px Outline Variant |
| 标题 | AppBar 左侧 | — | Title Large，22px，On Background |
| 新建按钮 | AppBar 右侧 | 高 40px | Filled Button，Primary，"+ 新建方法" |
| 搜索栏 | AppBar 下方 | 高 56px | Surface，内边距 16px，底部边框 |
| 搜索输入框 | 搜索栏内 | 高 48px | Outlined TextField，圆角 8px |
| 清除图标 | 输入框右侧 | 20px | On Surface Variant，有内容时显示 |
| 卡片网格 | 内容区 | 3 列，gap 16px | 流体布局，列最小宽 280px |
| 方法卡片 | 网格项 | 自适应 | Surface Container Highest，圆角 12px |
| 卡片标题 | 卡片顶部 | — | Title Medium，16px，500 |
| 编辑按钮 | 标题右侧 | 32px | IconButton，Primary |
| 删除按钮 | 编辑按钮右侧 | 32px | IconButton，Error |
| 描述 | 标题下方 | — | Body Medium，14px，2 行省略 |
| 参数徽章 | 卡片左下角 | 高 28px | AssistChip，Primary Container |
| 创建时间 | 卡片右下角 | — | Body Small，12px，On Surface Variant |

### 交互说明

- **Hover 卡片**: Elevation 1 → 2，背景叠加 On Surface 4%
- **点击卡片**: 导航到 `/methods/{id}/edit`
- **点击编辑按钮**: 同上
- **点击删除按钮**: 弹出删除确认对话框
- **输入搜索词**: 实时过滤卡片（debounce 200ms）

## 交互流程图

### 列表页流程

```
进入 /methods
  → Loading (Skeleton)
    → 成功
      → 有数据 → 显示 Card Grid
        → 搜索输入 → 实时过滤 → SearchEmpty / Data
        → 点击卡片 → 进入编辑页
        → 点击新建 → 进入新建页
        → 点击删除 → ConfirmDialog → API → 刷新
      → 无数据 → Empty
    → 失败 → Error (ErrorView)
```

### 编辑页流程

```
进入 /methods/:id/edit
  → id == null / new
    → 空白表单
    → dirty 初始 false
  → id 存在
    → Loading → API 获取 → 回填数据
    → dirty 初始 false

编辑中
  → 任何字段变化 → dirty = true
  → JSON 输入变化 → debounce 500ms 语法校验
  → 参数变化 → dirty = true

验证
  → 点击"验证"或自动触发
  → 通过 → Valid 徽章
  → 失败 → Invalid 徽章 + Footer 错误信息

保存
  → 点击"保存"
  → 全量校验
  → 失败 → Inline error + Toast Error
  → 通过 → API 调用 → Loading → Success Toast → 返回 /methods
  → API 失败 → Toast Error，保留表单

离开
  → dirty == true → UnsavedChangesDialog
  → dirty == false → 直接离开
```

### 参数 CRUD 流程

```
点击"+ 添加参数"
  → 打开 ParameterDialog（isEdit = false）
  → 填写字段
  → 点击保存
    → 校验通过 → 加入参数列表 → dirty = true
    → 校验失败 → 显示字段错误

点击"编辑"
  → 打开 ParameterDialog（isEdit = true，传入 parameter）
  → 修改字段
  → 点击保存
    → 校验通过 → 更新参数列表 → dirty = true
    → 校验失败 → 显示字段错误

点击"删除"
  → ConfirmDialog
  → 确认 → 从列表移除 → dirty = true
  → 取消 → 无变化
```
