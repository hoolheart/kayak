## Screen 1: 测点列表 — 有数据 (Desktop)

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ 设备详情面板                                                                 │

│ ─────────────────────────────────────────────────────────────────────────── │
│ ┌─────────────────────────────────────────────────────────────────────────┐ │
│ │ 测点列表                              共 3 个测点    [+ 添加测点]        │ │
│ ├───────────────┬────────┬──────┬──────┬──────────────┬───────────────────┤ │
│ │ 名称          │ 类型   │ 权限 │ 单位 │ 当前值       │ 操作              │ │
│ ├───────────────┼────────┼──────┼──────┼──────────────┼───────────────────┤ │
│ │ 温度传感器     │ Number │  RO  │ °C   │ ● 25.33 °C   │ ✏️  🗑️           │ │
│ │ 阀门状态       │ Bool   │  RW  │ —    │ ● 开启       │ ✏️  🗑️           │ │

│ [状态栏: 最后更新: 2026-06-01 10:00:00]                                    │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 元素规格

| 元素 | 位置 | 尺寸 | 样式 |
|------|------|------|------|
| 面板 | 右侧 | flex: 1 | Background 色 |
| 设备信息区 | 顶部 | 自适应 | Surface 色, 圆角 8px, 内边距 16px |
| 测点列表标题 | 头部左侧 | — | Title Medium, 16px, On Background |
| 测点计数 | 头部中间 | — | Body Medium, 14px, On Surface Variant |
| 添加按钮 | 头部右侧 | 高 36px | Filled Button, Primary |
| 表格 | 内容区 | 宽 100% | DataTable, 行高 52px |
| 表头 | 表格首行 | 高 48px | Surface Variant 50%, Label Medium |
| 类型标签 | 类型列 | 高 20px | 圆角 4px, 彩色背景 |
| 状态圆点 | 当前值列 | 8px | 圆形, 状态色 |
| 操作按钮 | 操作列 | 32px | IconButton |

### 交互说明

- **Hover 行**: 背景色变为 On Surface 4%
- **Hover 编辑按钮**: 背景 Primary 8%
- **Hover 删除按钮**: 背景 Error 8%
- **点击添加**: 打开 Screen 5 (添加对话框)
- **点击编辑**: 打开 Screen 6 (编辑对话框)
- **点击删除**: 打开 Screen 9 (确认对话框)

- **点击保存**: 验证 → API 调用 → 成功关闭 + Toast
- **点击取消**: 关闭对话框
- **点击遮罩**: 关闭对话框
- **按 Esc**: 关闭对话框

## 交互流程图

### 添加测点流程

```
点击"+ 添加测点"
  → 打开 PointFormDialog (isEdit: false)
    → 填写表单
      → 点击保存
        → 验证通过?
          → 是: API POST → 成功?
            → 是: Toast "测点已保存" → 关闭对话框 → 刷新列表
            → 否: 显示错误 → 保留表单
          → 否: 聚焦错误字段 → 显示 errorText
      → 点击取消
        → 关闭对话框
```

### 编辑测点流程

```
点击"编辑"
  → 打开 PointFormDialog (isEdit: true)
    → 加载测点数据 → 预填表单
      → 修改字段
        → 点击保存
          → 验证通过?
            → 是: API PUT → 成功?
              → 是: Toast "测点已保存" → 关闭 → 刷新列表
              → 否: 显示错误
            → 否: 聚焦错误字段
```

### 删除测点流程

```
点击"删除"
  → 打开 ConfirmDialog
    → 点击"删除"
      → API DELETE → 成功?
        → 是: Toast "测点已删除" → 刷新列表
        → 否: Toast 错误 → 保持列表
    → 点击"取消"
      → 关闭对话框
```
