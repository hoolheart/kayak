## 组件库 (Figma Components)

### Component: SelectableCard

| Variant | Property | Value |
|---------|----------|-------|
| State | Default | Surface, 1px Outline Variant |
| State | Hover | Elevation 2, Outline at 50% Primary |
| State | Selected | Primary Container, 2px Primary |
| Size | Desktop | 280px min-width |
| Size | Mobile | 100% width |

**Overrides**:
- Icon: IconData
- Title: String
- Subtitle: String
- Description: String (optional, 2 lines max)
- Selected: Boolean

### Component: ParameterField

| Variant | Type | Input Widget |
|---------|------|-------------|
| Type | number | TextFormField (decimal) |
| Type | integer | TextFormField (no decimal) |
| Type | string | TextFormField (text) |
| Type | boolean | Switch |
| Type | enum | DropdownButtonFormField |

**Overrides**:
- Label: String
- Unit: String (optional)
- Description: String (optional)
- Required: Boolean
- DefaultValue: String
- ErrorText: String (optional)
- Min/Max: Number (optional)

### Component: StepperHeader

| Variant | State | Visual |
|---------|-------|--------|
| Step | Inactive | Circle + Outline, text muted |
| Step | Active | Primary Container circle, bold text |
| Step | Completed | check_circle icon, Primary text |
| Step | Disabled | 38% opacity |

## 原型交互 (Prototype)

### 交互流 1: 完整创建流程

```
画板 1 (Step 1 Loading)
  → 自动 (After Delay 1s)
  → 画板 2 (Step 1 Data)

画板 2 (Step 1 Data)
  → 点击 "温度实验室" 卡片
  → 画板 5 (Step 1 Selected)
  → 点击 "下一步"
  → 画板 6 (Step 2 Loading)

画板 6 (Step 2 Loading)
  → 自动 (After Delay 1s)
  → 画板 7 (Step 2 Data)

画板 7 (Step 2 Data)
  → 点击 "标准热循环" 卡片
  → 画板 9 (Step 2 Selected)
  → 点击 "下一步"
  → 画板 10 (Step 3 Form)

画板 10 (Step 3 Form)
  → 输入 "200" 到目标温度
  → 画板 11 (Step 3 Error)
  → 清空持续时间
  → 画板 11 (Step 3 Error - 多字段)
  → 修正输入
  → 画板 10 (Step 3 Valid)
  → 点击 "下一步"
  → 画板 13 (Step 4 Confirm)

画板 13 (Step 4 Confirm)
  → 点击 "创建试验"
  → 按钮 Loading 状态 (200ms)
  → 画板 15 (Success Toast)
  → 自动 (After Delay 2s)
  → 导航到实验详情 (外部链接)
```

### 交互流 2: 步骤回退

```
画板 10 (Step 3)
  → 点击 "上一步"
  → 画板 9 (Step 2, 方法保持选中)
```

### 响应式行为标注

在所有 Desktop 画板右下角添加标注:
```
Breakpoint: > 1200px
- Stepper: Full labels
- Cards: 2-3 columns
- Form: 2 columns
- Buttons: Inline
```

在所有 Mobile 画板右下角添加标注:
```
Breakpoint: < 600px
- Stepper: Short labels
- Cards: 1 column
- Form: 1 column
- Buttons: Stacked full-width
```

### 无障碍标注

- 所有交互元素最小触摸目标: 48×48dp
- 颜色对比度: 文字 ≥ 4.5:1, 大文字 ≥ 3:1
- 步骤指示器: aria-label 描述当前步骤
- 表单字段: label 与 input 正确关联
- 错误提示: role="alert" 自动播报

### 性能标注

- 步骤切换动画: 使用 Fade + Slide, GPU 加速
- 骨架屏 shimmer: 使用 ShaderMask, 避免布局抖动
- 卡片网格: 使用 Wrap + ConstrainedBox, 避免重排
- 表单验证: 防抖 300ms, 避免频繁验证
