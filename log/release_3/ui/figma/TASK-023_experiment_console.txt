## 原型交互 (Prototype)

### 交互流 1: 完整试验生命周期

```
画板 7 (Loading)
  → 自动 (After Delay 1s)
  → 画板 2 (IDLE)

画板 2 (IDLE)
  → 点击 [载入] 按钮
  → 画板 8 (载入 Loading)
  → 自动 (After Delay 800ms)
  → 画板 3 (LOADED)

画板 3 (LOADED)
  → 点击 [开始] 按钮
  → 画板 8 (开始 Loading)
  → 自动 (After Delay 800ms)
  → 画板 1 (RUNNING)

画板 1 (RUNNING)
  → 点击 [暂停] 按钮
  → 画板 8 (暂停 Loading)
  → 自动 (After Delay 800ms)
  → 画板 4 (PAUSED)

画板 4 (PAUSED)
  → 点击 [继续] 按钮
  → 画板 8 (继续 Loading)
  → 自动 (After Delay 800ms)
  → 画板 1 (RUNNING)

画板 1 (RUNNING)
  → 点击 [停止] 按钮
  → 画板 9 (确认对话框)
  → 点击 [确认停止]
  → 画板 8 (停止 Loading)
  → 自动 (After Delay 800ms)
  → 画板 5 (COMPLETED)
```

### 交互流 2: WS 断线重连

```
画板 1 (RUNNING, connected)
  → WS 断开 (模拟)
  → 画板 13 (重连中 1/5)
  → 自动 (After Delay 1s, 重连失败)
  → 画板 13 (重连中 2/5)
  → 自动 (After Delay 2s, 重连成功)
  → 画板 1 (RUNNING, connected)

画板 1 (RUNNING, connected)
  → WS 断开
   → 画板 13 (重连中... 循环至 5/5)
  → 自动 (After Delay, 全部失败)
  → 画板 14 (连接失败)
  → 点击 [重新连接]
  → 画板 12 (连接中)
  → 自动 (After Delay 800ms, 成功)
  → 画板 1 (RUNNING, connected)
```

### 交互流 3: 日志交互

```
画板 1 (RUNNING, 日志在底部)
  → 用户向上滚动日志
  → 画板 11 (显示浮动按钮 "2 条新日志")
  → 点击浮动按钮
  → 平滑滚动到底部
  → 画板 1 (浮动按钮消失)

画板 1
  → 点击 Filter Dropdown
  → 选择 "INFO"
  → 画板 10 (仅显示 INFO 日志)
  → 点击 Filter Dropdown
  → 选择 "全部"
  → 画板 1 (显示所有日志)

画板 1
  → 点击 [清空日志]
  → 日志清空
  → 显示空状态
  → [清空] 按钮变为 disabled
```

## 标注与说明

### 响应式行为标注

在所有 Desktop 画板右下角添加:
```
Breakpoint: ≥1200px
- Layout: 左右分栏 38:62
- Panel: radiusLarge, elevation 1
- Buttons: 水平双行
- Timer: 36px monospace
```

在所有 Tablet 画板右下角添加:
```
Breakpoint: 600-1200px
- Layout: 左右分栏 40:60
- Panel: radiusLarge, elevation 1
- Buttons: 水平，空间不足换行
```

在所有 Mobile 画板右下角添加:
```
Breakpoint: <600px
- Layout: 上下堆叠
- Panel: 顶部，自适应高度
- Buttons: Wrap 排列，min 48px height
- Timer: 32px monospace
```

### 无障碍标注

- 所有交互元素最小触摸目标: 48×48dp
- 颜色对比度: 文字 ≥4.5:1, 大文字 ≥3:1
- 状态徽章: aria-label 描述当前状态
- 按钮: aria-disabled 反映禁用状态
- 日志区: role="log", aria-live="polite"
- 确认对话框: aria-modal="true", 焦点限制在对话框内
- 计时器: aria-label="已运行时长 2小时15分32秒"

### 性能标注

- 日志列表: 使用 ListView.builder + itemCount
- 最大保留日志: 1000 条 (滚动性能)
- 计时器更新: Timer.periodic(Duration(seconds: 1))
- 页面 dispose: 取消 Timer, 断开 WS
- 骨架屏: ShaderMask shimmer, 避免布局抖动
- 脉冲动画: 使用 AnimatedBuilder, 避免重建整个 Widget
